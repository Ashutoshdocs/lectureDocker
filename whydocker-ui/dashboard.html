Java runtime control panel

Same VM. One page the old way, two pages with Docker.

On the left you can switch the machine's single Java runtime — only one app page can be live at a time. On the right, Docker runs both Java versions in separate containers, at once. Watch the live previews as you click.

The VM way — one runtime slot

The host has a single system Java. Start one version and the other stops — there's only ever one page, on port 8080.

Each version ships its own runtime in its own container. Build once, then run both — both pages stay live together, on ports 8081 and 8082.
